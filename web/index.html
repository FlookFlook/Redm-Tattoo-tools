เลเยอร์ลาย

หรือลากไฟล์รูป / .ytd มาวางบนพื้นที่วาด — PNG พื้นใส หรือ JPG/PNG หมึกดำบนพื้นขาว · .ytd ลงเป็นเลเยอร์บนภาพ UV ตรงตำแหน่งเดิม (ชื่อลงท้าย _fr / _f = ของหญิง · _legs = ขา)

    ไกด์ (ลายเดิมในเกม)

    ลายเดิมวางตามตำแหน่งจริงบนตัว ใช้ดูว่าแขน / อก / หลัง อยู่ตรงไหนของภาพ

    ตัวโมเดล 3D

    คูณสีผิว

    เลือก "+ โหลดไฟล์ผิวเอง" ในรายการ (.ytd / .dds BC1-BC3 / .png) หรือใส่ไฟล์ใน tex/ แล้วรัน build_model.py ใหม่

    เสื้อผ้า / โมเดลเสริม

    เลือกไฟล์ .ydd.xml ที่ export จาก CodeX (เลือกหลายไฟล์ได้) — ใส่ .ytd / .dds ของเสื้อผ้า มาพร้อมกันจะได้สีจริง ไม่ใส่ใช้สีเรียบ · ชื่อมี mr1 = ชาย / fr1 = หญิง · ดูอย่างเดียว คลิกทะลุไปที่ผิว

      สีเสื้อผ้า (ชิ้นที่ไม่มี texture)

      มุมมอง

      ขอบตัว (คอ / เอว) — ลายเลยเส้นนี้ไปจะหาย

      รอยต่อชิ้น — ผิวต่อกันบนตัว แต่ลายต้องไปต่อที่อีกชิ้นเอง

      ลบเฉพาะเลเยอร์ที่เลือก · ลากบนตัวหรือบนภาพ UV · [ ] = ขนาดแปรง · ลากที่ว่างบนตัว 3D = หมุนกล้อง

      รูปในร้านจะได้เฉพาะในกรอบนี้
      ลากที่ว่าง = หมุน · ล้อ = ซูม · คลิกขวาลาก = เลื่อน · ปุ่มมุมมองด้านบนใช้ได้
      ลากผิวเปล่า / ที่ว่าง = หมุน · ลากตรงลาย = ย้าย · Alt+คลิกลาย = แยกชิ้นตามรอยต่อ · ดับเบิลคลิก = ย้ายลายที่เลือกมาตรงนั้น · ล้อ = ซูม · Shift+ล้อ = ขนาดลาย · Ctrl+ล้อ = หมุนลาย · คลิกขวาลาก = เลื่อนกล้อง
      ยังไม่มีเลเยอร์ ลาก = ย้าย · จุดจับมุม/ขอบ = ย่อ/ยืด · Alt+คลิก = แยกชิ้น · ล้อเมาส์ = ย่อ/ขยาย · Shift+ล้อ = หมุน · ลูกศร = ขยับทีละ 1 (Shift = 10) · Del = ลบ · Ctrl+D = ทำสำเนา · H / V = กลับด้าน

      เลเยอร์ที่เลือก

      คลิกลายบนพื้นที่วาด หรือเลือกจากรายการทางซ้าย

      ทุกแบบยกเว้น "บนภาพ UV" ต่อข้ามรอยต่อเอง · ติดตามผิว = ไม่ยืดตรงที่โค้ง · ฉายตรง / ฉายจากกล้อง = เหมือนฉายโปรเจกเตอร์ ตรงโค้งจะยืด · ห่อรอบ = ปลอกแขน / รอบน่อง

      แปลงรูปเป็นหมึก

      ลายสีย้อมสีหมึกในร้านไม่ได้ ถ้าในไฟล์มีเลเยอร์ลายสี ทั้งไฟล์จะส่งออกเป็นลายสี (ส่วนที่เป็นหมึกเดียวกลายเป็นสีดำ)

      ส่งออกเป็นลายในร้าน

      ช่วยให้ลายคมในเกม (ผิวในเกมมีแค่ 512 — พรีวิวปกติคือขนาดเดียวกับในเกม)

      หนาเส้น / คมขึ้น ใช้กับทุกเลเยอร์ตอนส่งออก (เห็นในพรีวิวทันที) · 1 จุด ≈ 2 มม. บนตัว

      ชื่อไฟล์ต่อท้ายตามเพศ: ชาย = _mr · หญิง = _fr (ขา = _legs_mr / _legs_fr) · ชายและหญิง = ได้ไฟล์แยกของแต่ละเพศ ตามตำแหน่งที่จัดไว้ของแต่ละเพศ · ชายหรือหญิงเท่านั้น = ไฟล์เดียว ตัว 3D สลับไปเพศนั้นให้

      รูปในร้าน (256 × 256 — กรอบนี้คือรูปที่ได้จริง)
      ลากรูปมาวางตรงนี้ หรือคลิกเลือกรูป
      ไม่ใส่ = ครอปจากลายบนภาพ UV ให้

      ลากในกรอบ = เลื่อนรูป · ล้อเมาส์ = ซูม · ดับเบิลคลิก = พอดีกรอบ
